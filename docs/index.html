Shrake-Rupley estimates each atom's area by sampling its surface, so this slider trades accuracy for speed. The numbers above move as you drag it, which is the sampling error made visible.

Relative solvent accessibility

Each residue's area in the folded structure divided by the same residue's area measured on its own, with every other atom removed. Both halves come from the same code, so there is no table of per-residue maxima to trust. Bars under 25% are counted buried, the conventional cutoff.

Hover a bar for the residue.

Residue contact map

Two residues count as in contact when their beta carbons fall within 8 A, with the alpha carbon standing in for glycine, which has no beta carbon. Dark means close. The diagonal stripe is the backbone; blocks away from it are strands or helices packed against each other.

Hover the map for a residue pair.

What this page is doing

  1. Downloads the mmCIF file from files.rcsb.org and the entry record from data.rcsb.org. Both send access-control-allow-origin: *, so there is no backend here, no proxy and no secret.
  2. Parses the atom_site loop with a hand-written reader: column order read from the loop header, quoted and semicolon text fields, null markers. Keeps the first model and resolves alternate conformers by occupancy.
  3. Runs Shrake-Rupley solvent accessibility. Each atom gets a golden-spiral lattice of test points on a sphere of radius r + 1.4 A; a point counts as accessible if it falls outside every neighbouring atom's own extended sphere. Neighbours come from a uniform cell grid.
  4. Builds the beta-carbon contact map and fills the summary template.

The Python package in this repository implements all of the above a second time, and a test runs these exact JavaScript files under node to confirm the two agree. On the structures tested the per-atom areas come out bit-identical.
